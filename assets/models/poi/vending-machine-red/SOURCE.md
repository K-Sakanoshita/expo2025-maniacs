The model represents a common Japanese beverage vending-machine design and is used as a generic 3D symbol for OpenStreetMap `amenity=vending_machine` features. The two source textures are resized to a maximum of 1024px for web-map performance; geometry is unchanged.

Local variant by EXPO2025 Maniacs Map. Geometry is unchanged; the cabinet uses a replacement texture. Original attribution and CC BY 4.0 license apply to the original model.

Expo-inspired variant: `textures/EXPO2025_body.png` is an AI-generated UV texture based on the user-provided vending-machine reference. White cabinet, red bands, and blue/red motifs approximate the reference; the cabinet's Expo and Coca-Cola logos are omitted. This is not a faithful reproduction of the original Expo machine. The blue model is unchanged.

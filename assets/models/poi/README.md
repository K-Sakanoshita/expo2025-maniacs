# Park facility 3D models

These models are used as compact 3D symbols for selected OpenStreetMap park facilities.
They indicate the mapped feature type and do not claim to reproduce the exact real-world object.

| --- | --- | --- |

| `amenity=vending_machine` | `vending-machine/scene.gltf` | JPN vending machine by adenotoxin — CC BY 4.0 |
